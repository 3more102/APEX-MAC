# FPGA Implementation

The target FPGA board is not selected yet. Do not assume a specific device until board availability is confirmed.

Record:
- Board and FPGA part number.
- Tool and version.
- Clock and I/O constraints.
- Synthesis and implementation settings.
- LUT, FF, DSP, BRAM and clocking resource use.
- Post-route timing and power-estimation assumptions.
- Hardware test procedure and measured results, if a board is available.

FPGA resource and power results must be reported separately from ASIC standard-cell results.
