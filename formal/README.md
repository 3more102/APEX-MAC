# Formal Verification

Formal harnesses and properties will be added after the RTL handshake and reset protocol are frozen.

Planned proof targets:
- Error-budget safety.
- Precision selection correctness.
- No transaction loss or duplication.
- Accumulator overflow detection.
- Atomic accumulation-window reset.

The proof assumptions and parameter bounds must be documented. A passing bounded check must not be described as an unbounded proof.
